# UI1-A1 调用日志统一查询实施契约

状态：2026-10-26 完成 UI1-A1 首轮隔离验收，基线 main `9552e2bfd2b0dae534e775c07a4933c508ab0082`。架构事实源已先更新；本契约细化既有 UI0。尚未发布生产，前端与导出属于下一批。

## 1. 首批边界

两个现有 GET 路由显式 `filter_version=1` 时返回同筛选列表和合计。旧路径不变；不把未知版本当旧请求。无新路由、无 UI/CSV/字典/视频接口变更、不改账务或迁移。后续正常请求兼容适配及导出统一单独验收，不能把 A1 说成全站日志完成。

## 2. 分层与接口

- `invocation` 领域拥有只读查询、标准 Filter、授权 Scope、Totals/Result；Scope 分平台与正整数 Org，不允许零 Org 默认扩大为全平台。首批只从两个已经授权的控制台 handler 调用。
- `server/invocation_filters.go` 解析严格 URL 参数并生成规范化 DTO/hash；`server/invocation_query.go` 执行并发槽、共享 context、FX、领域调用和返回字段。仅在 admin.go/usage.go 两入口分派；server.go 允许增加零值可用的实例并发门禁字段，不能另注册路由。
- 私表 SQL 不落在新增 server 查询代码；不把全平台 Scope 暴露为客户端参数。新接口直接传入既有配置读库，单响应在同一数据库连接和只读 REPEATABLE READ 事务查询；权限仍由主库中间件核对。

## 3. FilterSpec 与响应

v1 允许固定 source=invocation_log/time_basis=recorded_at、有效 IANA timezone、绝对 since/until 或日期范围、model、request_id、api_key_id、modality、result 或 status、is_stream；管理员另有 org_id/channel_id。禁止未知、重复、冲突、非法枚举、超长字段、非法 ID/时间；组织端即使提供合法 org/channel 也拒绝。统一 `[since,until)`；默认以当前时区今日在内七个自然日的起止，最多九十个自然日（按指定 IANA 时区 AddDate，跨 DST 也按自然日）；显式绝对时间不再加一天。since/until 要么同时提供，要么同时缺省；日期按指定时区，完整时间必须有明确偏移，拒绝 Local 隐式时区。page 正整数，page_size 20/50/100，offset 最大100000且无溢出，id DESC。

显式 filter_version=1 本身就是聚合 opt-in，不再增加 include_totals 第二开关；保留 items/total/page/page_size，添加 query 与 totals。query 记录规范化筛选、含授权 scope 的 filter_hash、as_of、consistency=response_snapshot、跨请求 live、数据/金额来源与完整性，以及固定 display_money；hash 不含 page/currency，但客户端不能只靠 hash 识别完整响应上下文。as_of 不承诺跨请求历史重现。

Totals 包括记录数、success/非 success、prompt/completion/cached/reasoning Token、cost_usd 及显示金额。Token 汇总、金额均十进制字符串；缓存/推理为子项，不能再加进输入/输出总数。missing_usage_count=null、usage_presence=legacy_not_distinguishable。普通行 DTO 沿用既有隐藏规则，管理 DTO 显式列字段。不得新增正文、Key hash、供应商凭据或自由 SQL 到响应/日志。

## 4. 查询与资源边界

每实例全局四个重查询槽、同主体两个，具名用户按当前身份 ID，兼容共享管理 token 为单固定桶。零等待、满载 429；每次进入都有 defer 释放，空桶移除。v1 业务阶段（FX+查询）统一三秒 context，身份中间件不包含在该时限声明中。SQL/连接等待/事务全部使用该 context；每条 MySQL SELECT 还应设置不超过剩余期限的执行时间提示。无完整结果就不返回成功或假零。

只读 RR 事务的两条查询分别为全条件 COUNT/SUM 聚合、固定 id DESC 分页；使用相同标准化谓词，禁止 GORM 已执行链重复使用。普通精确 request/Key 查询也始终带 Org。FX 读取复用现有规则和 parseCNYPerUSD，一次观测；缺设置/空值可按既有默认值并标 source，非空非法值或读取故障为503，不能误用 getSetting 吞错误。原支付/CSV行为不改。展示换算 Decimal，不写余额/价格。

## 5. 文件归属与验收

领域实现线：`core/internal/invocation/query*.go`；服务端线：`core/internal/server/invocation_filters.go`、`invocation_query.go`、同前缀单测与上述三个最小集成点；验收线：独立 fixture/oracle、HTTP/MySQL 测试文件，不能复制生产 SQL 当 oracle。各线接口冻结后并行，主控独立审查和统一 CI。

通过 make vet/make ci、相关真 MySQL/race 后独立 PR；后续 UI/CSV 另需 make ci-all 与浏览器验收。本批不证明500在途。

首批实现 API 固定：Invocation 领域使用 QueryFilter、QueryScope、QueryTotals、QueryResult，`OrganizationQueryScope(orgID)` 返回组织范围，`AdminQueryScope()` 由后台鉴权后的服务端调用，`QueryLogs(ctx, db, scope, filter, page, pageSize)` 返回领域结果。字段在开发线之间先消息对齐再写消费者；新 Scope 零值不可用。领域查询共用同一个只读事务，数据库返回数量使用int64计数（记录总数），各Token与金额用精确字符串；普通逐行Token既有number不在本批精度迁移范围。
