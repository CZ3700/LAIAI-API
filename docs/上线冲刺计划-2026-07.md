## 批次 1 —— Playground 视频生成（新需求，约 1.5-2 天）

前端为主，后端预期零改动（任务 API 三件套已备：`POST /v1/video/generations` → 轮询 `GET .../{id}` → 产物直链或 `/content` 代理）。

- **模态扩展**：Playground `mode` 增加 `'video'`（`modelCatalog.modelModality()` 已能按名/元数据识别 seedance/sora/veo/kling/hailuo/wan 等）
- **表单**：prompt + 可选参考图 URL（image_url 进 content 数组）+ 可选参数 duration/resolution/ratio（透传，空=厂商默认）；显示模型单价与"按时长×分辨率计费"口径提示
- **进度**：提交后轮询（~5s 间隔），queued/running 态 + 耗时计时；task id 存 sessionStorage（刷新页面可恢复跟踪）；失败/余额不足给可读错误
- **成片与下载**（关键技术点：`<video>` 无法带 Authorization 头）：
  - 直链产物（seedance 等 result_url 为 http(s)）→ `<video :src>` 原生播放 + 新窗下载
  - 平台代理产物（sora/veo 的 `/v1/video/generations/{id}/content`）→ fetch + Bearer → blob → objectURL 播放与下载（Playground 短片体量可接受）
- i18n ×9；**真机验收用 seedance**（唯一已真机验证厂商，与需求点名吻合）

**验收**：充值账号在 Playground 选 seedance → 出片 → 页内播放 → 下载成功；失败路径错误可读；费用按实结算与日志可见。
