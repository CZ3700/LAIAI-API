## 售价、预冻结与结算

两个模型分别有四个价格组合：480p/720p × 有无参考视频。当前 USD 售价按既有汇率 `0.148765248438 USD/CNY` 换算，不另加价。

| 模型 | 输入条件 | 官方成本 CNY/百万 Token | 客户售价 USD/百万 Token |
| --- | --- | ---: | ---: |
| Fast | 无参考视频 | 37 | 5.504314192206 |
| Fast | 有参考视频 | 22 | 3.272835465636 |
| Mini | 无参考视频 | 23 | 3.421600714074 |
| Mini | 有参考视频 | 14 | 2.082713478132 |

预冻结系数 **4** 来自现有平台风险政策，不是官方价格，也不是客户售价倍率。

```text
公式估算 Token = ceil((输入视频时长 + 输出视频时长) × 输出宽 × 输出高 × 24 / 1024)
有参考视频时的基准 Token = max(公式估算 Token, 对应最低规则)
无参考视频时的基准 Token = 公式估算 Token
预冻结 Token = ceil(基准 Token × 4)
预冻结金额 = 向上取整至 8 位小数(预冻结 Token × 客户单价 / 1,000,000)
实际结算金额 = 按 8 位小数四舍五入(completion_tokens × 冻结快照中的客户单价 / 1,000,000)
```

时长按秒表示；实现使用毫秒、整数与 Decimal 运算。已验证素材按实测时长计算，未验证参考视频使用 15 秒的已配置总时长上界。自动输出时长按已验证能力上限预冻结。

结算不再次叠加最低量、输入 Token 或风险系数。缺失实际用量时保持待核算，不能以预估值冒充实际用量。余额变更与账本在事务内同写；重复查询及幂等重试不产生第二次扣费。实际用量超过预冻结时继续保留真实供应商成本并触发原有风险处置，不能通过裁剪用量隐藏差额。
