## API 兼容性

`content_url` 是上游视频签名 URL；`content.video_url` 与其一致，`content.last_frame_url` 在上游提供时存在。`artifact_status=ready` 只表示取得链接，不承诺永久托管。

`GET /v1/video/generations/{id}/content?kind=video|last_frame` **从媒体二进制改为链接 JSON**：`{url, kind, source: "upstream"}`。原下载客户端需先解析 JSON，再直接访问 URL；平台 Bearer Key 只能用于网关请求，不应发送到 CDN。接口不通过跨域 302 传递鉴权。见[OpenAPI](api/seedance-v1.openapi.yaml)及[调用示例](api/seedance-integration-examples.md)。

任务与账务继续持久化。Invocation Store 的最小 `delivery` 胶囊只保存校验后的加密链接元数据，保留签名参数；每份至多 24 小时，且不超过任务创建时间加 `RetentionDays`。列表只读缓存；单任务详情及 `/content` 可在保留边界内受限查询原账户的官方任务并回填，不创建新视频、不重新结算。查询能否得到仍有效的地址由火山决定。旧产物文件保留，当前部署不挂载该卷；输入素材模块维持原契约。

## 真实生成与异步机制

四款模型的真实测试均采用纯文本、480p、4 秒、1:1，估算 38,400 Token，实际返回 38,800 Token。Mini、Fast、2.0 通过脚本提交并验证立即幂等重放；2.5 在参数修复后通过真实浏览器创建。前三款显式关闭音频，2.5 使用页面默认值，不宣称四项参数完全相同。

| 模型 | 终态 | 新增供应商应计 CNY |
|---|---|---:|
| Seedance 2.0 Mini | succeeded / settled / ready | 0.8924 |
| Seedance 2.0 Fast | succeeded / settled / ready | 1.4356 |
| Seedance 2.0 | succeeded / settled / ready | 1.7848 |
| Seedance 2.5 | succeeded / settled / ready | 2.7160 |
| 合计 | 4 条成功任务 | **6.8288** |

总新增应计低于本次授权 10 CNY。每项确认一次上游提交及一次初始结算；全额供应商费用、客户冻结上限、平台承担差额及账本守恒通过检查。正式供应商账单未完成对账，应计不等于对账确认。

首次 2.5 因不适用的参考模式字段被官方明确拒绝；该任务只发送一次，无上游任务绑定，客户冻结全额释放，实扣与供应商应计为 0。修复后使用新任务完成验证，原失败证据保留。前三款在前一候选构建成功，2.5 在修复后的构建成功；没有重复付费重跑前三款。

创建接口在数据库事务内完成权限、价格和预算校验、冻结及派单意图后返回 202。后台 leader 每 2 秒执行一轮，每供应商作用域每轮最多派发一个创建请求，数据库按作用域和动作限速，外部 HTTP 串行处理。已受理任务在持久化队列中等待；查询名义间隔至少 10 秒，慢请求会延长实际间隔。

验收配置的共享在途上限为 3；`accepted / submitting / submission_unknown / queued / running` 占用名额，第 4 条请求返回 429。上限是配置事实，不是所有部署固定值。已持久化回执支持重启后恢复而不重复 POST；Fast 在 running/reserved 时重启 core 后恢复成功，仍为一次发送。缺少回执或上游 ID 的 `submission_unknown` 保持冻结及占位，不能盲目重发。

## 验收限制与后续放行条件

直链 URL 在本机 Chrome 打开时显示 `ERR_BLOCKED_BY_CLIENT`。未修改或绕过浏览器保护，也未为测试在平台下载媒体。因此本轮不能宣称真实浏览器直链播放、文件保存或出站请求头抓取通过；该阻断也不能证明火山资源失效。先前平台媒体流模式的播放、API 下载和全片解码是历史证据，不能替代当前直链播放验收。

部署范围仅为本地生产模式。公网 TLS 与代理信任链、长期压力与多副本故障、跨机器加密恢复、成功运行后的完整回退、无回执未知提交的人工处置及逾期告警、正式供应商账单、其他输入媒体组合和适用素材/H5 权益仍需独立验收。操作步骤及回退边界见[生产 Runbook](生产runbook.md#7-seedance-直链版本部署与验收2026-10-21)。
