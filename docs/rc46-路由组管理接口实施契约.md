## 1. 边界与身份

B1完整闭环为创建draft组→CAS编辑/启停→绑定/解绑→有限查询和结构预览。只支持现有平台组和同Org私有组边界；不创建组织授权、不切默认组、不开放grouped Key。B2单独补grant/default HTTP。所有成功响应附grouped_key_issuance_enabled=false。

挂载在现有`/api/admin`，仅活跃具名superadmin会话。拒绝共享root token、API Key、普通用户及Org管理员；actor取主库核验后的会话UserID，requestID由服务端生成。既有身份middleware数据库故障可能为401，只承诺拒绝，不宣称已改全局错误协议。业务DB错误为安全503，参数400、缺资源404、CAS409 `policy_version_conflict`、归属拒绝403、繁忙429。无原始错误/SQL/正文日志。

## 2. 接口

| 方法/路径 | 输入 | 成功含义 |
| --- | --- | --- |
| GET /routing-groups | 可选owner_org_id、status、cursor、limit | ID升序seek，默认20、最大100；不返回总量伪精确值 |
| POST /routing-groups | owner_org_id必填（0平台）、slug/name、description可选 | 仅draft/version1；不接收status/actor/version |
| GET /routing-groups/:id | 无 | 显式安全组DTO |
| PATCH /routing-groups/:id | expected_version必填正整数；name/description/status至少一项 | 未提供字段保留；owner/slug不能改；重复配置也核验CAS |
| GET /routing-groups/:id/channels | cursor、limit | channel_id升序seek；绑定+有限channel摘要 |
| PUT /routing-groups/:id/channels/:channel_id | expected_group_version必填 | 同事务验证当前归属，返回changed及group新版本 |
| DELETE /routing-groups/:id/channels/:channel_id | expected_group_version必填JSON | 只解绑，保留渠道、任务及历史 |
| POST /routing-groups/:id/impact-preview | expected_version、change对象 | 只读；change.kind为update/bind/unbind，字段沿对应命令 |

JSON大小上限16KiB，拒绝未知字段、重复键（含嵌套）、额外顶层JSON、显式NULL、非对象。URL查询拒绝未知/重复键、非法枚举/ID/游标。ID/版本只接受整数，不经float解析；缺少CAS为400，过期为409，无force。

预览返回preview_kind=structure_only、observed_group_version、规范化拟变更、grouped_key_issuance_enabled=false、effective_model_impact_available=false。不发随机Key、不写事件、不调用上游、不临时执行再回滚写命令。

## 3. 领域与资源约束

identity本域新增真实事务的Org当前读锁，relay本域新增真实事务的Channel当前读锁和有限批量摘要。入参IDs正数、升序去重、最多100；不能在接口内另开事务。锁返回安全{id,owner/status/active}事实；摘要仅id/name/provider/status/owner，不读取凭据/地址/model mapping。宿主bridge只映射领域DTO，routinggroup不跨域直碰私表。

routinggroup新增管理读服务：所有自己的SQL、组过滤、绑定分页与grant/default结构计数归本域；渠道摘要通过传入接口在同一只读RR事务和context读取。每请求主库业务读共用1秒（鉴权另计），每SELECT MySQL MAX_EXECUTION_TIME<=200ms且不超过剩余期限；拒绝套入调用者已有事务，不返回部分成功。列表最多100+1、摘要批量<=100。预览每类关系最多1000+1探测；只统计前1000条，返回observed_count/exact/lower_bound/limit=1000，截断明确为下界；default指针数不叫有效授权数。观察结果和拟变更不承诺跨请求快照，最终写命令仍重新锁定复核。

server每实例业务读全局4/每具名UserID2个槽，零等待；完成/错误/取消均释放，空主体桶删除。写命令沿用G1-A的5秒事务期限、Org→Group→Channel→关系→event锁序及CAS。新读写会话局部关闭继承SQL日志，不修改全局Logger。绑定预览也核验平台/私有归属，不能把不可能提交的操作说成可行；组状态/角色/渠道变动后写入重新校验。

不新增迁移/索引，先通过真实EXPLAIN与有界查询；无任何价格、余额、Key模式、Task、渠道配置写入。绑定只写自己的关系、组版本和事件。
