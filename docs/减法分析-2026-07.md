# 减法分析 — 2026-07（全代码实读审计）

> 六视角减法审计（36 agent 实读全部 26 页面/35 admin 端点/relay/payment 代码），
> 每个候选裁减项经"怀疑者"反向验真（删了会坏什么）。三档结论：
> **A=无争议可砍**（多视角同判+验真通过）/ **B=可砍但有代价**（需拍板）/ **C=看似冗余实则承重**（明确不砍）。
> 分析报告，未动代码。

## 总评

产品的"多"集中在**观测面**（5 个页面看同一份调用数据）和 **Admin 面**（12 tab 有 3 处成对重复）；
内核（路由/计费/任务/安全）没有发现值得删的东西——那里的复杂度都在承重。
支付 8 引擎中 1 个（x402）是端到端不可用的半成品。

## A 档：无争议可砍（验真全过，核心体验零损失）

| # | 砍什么 | 证据 | 损失 |
|---|---|---|---|
| A1 | **删 TokenAnalysis 页**（4 视角独立同判） | 调用与 Usage 完全相同的两个端点，渲染 Usage 的严格子集，且部分筛选控件是**无功能装饰**（TokenAnalysis.vue:150 行全页） | 仅"平均 token/次"卡片——一行公式，可加回 Usage 当第 6 张卡 |
| A2 | **ImageLogs 并入 RequestLogs**（3 视角同判） | 同端点(/api/usage)、窗口逻辑逐字复制、只是硬编码 modality=image+少几列（213 行全页） | 无。RequestLogs 加一个"全部/文本/图像/视频"模态筛选即覆盖，还白得详情抽屉 |
| A3 | **删 Billing 的 usage tab** | RequestLogs 的劣化拷贝，且带两个永远显示"—"的死列（Gift/Paid，Billing.vue:222-223）；monthly tab 也是单行硬编码+死列 | 仅"在账单页顺便瞄一眼最近 20 条调用"，RequestLogs 一跳即达 |
| A4 | **删 2 孤儿端点 + 1 死组件** | /usage/perf 与 /usage/by-model-daily 全前端 **零调用方**（grep 验证）；StackedBarChart.vue 无人 import | 无（从未被渲染过）。⚠️ /usage/export 有真实价值（CSV 自助导出），**保留** |
| A5 | **删 admin 死端点 /api/admin/payment-config** | 零前端调用，读的还是被 payment-channels 表**取代的旧 settings 键**（stripe_secret_key 等 legacy） | 无 |
| A6 | **x402 引擎 mothball** | 前端 **零代码**（无钱包签名端）——返回的 paymentRequirements 没有任何页面能消费，端到端不可用；最投机的轨道且默认已关 | 无（本来就没人能用它付款）。代码留库不删，摘出启用路径即可 |
| A7 | **Custom/Webhook 引擎 helper 去重** | 两引擎 7 个 helper 是功能双胞胎（dot-path 提取/默认值/摘录），纯代码重复 | 无（引擎本身保留——方言差异真实，只去重底层函数） |

**A 档合计效果**：用户侧 26 页 → 24 页；观测导航 5 项 → 3 项；死代码 -~700 行；支付活跃面 8 → 7。

## C 档：看似冗余，实则承重（明确不砍，防将来误伤）

- **Models（公开）vs ConsoleModels（控制台）**：REJECT——控制台版的接入片段生成器是主 onboarding 路径
- **Dashboard vs Usage**：Dashboard 是唯一"余额+充值+成功率+排行"全景首页，角色不同
- **RequestLogs 详情抽屉**：全站唯一请求级排障面（upstream_request_id/错误码/finish_reason）
- **Admin logs vs audit**：调用观测 vs 管理员操作合规轨迹，保留策略都不同（两个 retention 旋钮）
- **Realtime WS**:唯一 realtime 模态网关，真实 API 面不是投机
- **9 家任务厂商**：广度即护城河（尤其国产覆盖），一家都不砍
- **Coinbase + CryptoGateway 两条 crypto 轨**：wire 协议不同不可互代；都保持 dormant 但代码都留
- **Multi-key 三模式/override 保护键清单/QueryOrder 对账腿**：全是资金/安全承重结构
- **Diagnostics 页**：独立排障工作，非 Playground 重复
- **Rankings 公开页**：SEO/营销面，不占控制台导航
