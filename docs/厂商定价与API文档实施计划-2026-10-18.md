# 厂商定价与 API 文档实施计划

基线：`e6104c94e1abb5d8320f0652ab8b133a9e15dec2`（PR #24）。本轮按用户要求先形成方案再实施，保留既有 USD 售价，优先填充 Seedance 2.0、2.5，排除 Seedance 1.x 配置。参考站只作为目录与内容覆盖参考，公开契约以本平台实际代码为准。

## 一、定价入口

管理后台定价先选择已接入厂商，可再按渠道筛选，再选择该范围内真实模型。来源是渠道模型清单、公开名映射、模型元数据、适配器能力和官方视频配置；不以名称包含 video/image 推测收费。未知分类明确待识别。禁用渠道仍可配置，但显示状态。

| 模型计价 | 编辑内容 | 保存边界 |
|---|---|---|
| 文本 Token | 输入、输出、缓存及已有扩展单价 | 复用通用模型价格；隐藏字段保留原值 |
| 图片 | 已实现的按张或模型现有单位 | 按真实价格模式显示，不强制套入输入/输出 |
| 官方 Seedance | 模式、分辨率、是否参考视频、Draft、服务层级、USD 售价、CNY 成本、最低量、冻结系数 | 复用版本发布与校验，历史快照不重算 |
| 其他已接入类型 | 当前真实计价单位或待配置说明 | 不强行改成文本价格 |

厂商/渠道是发现及筛选入口，不新造按渠道独立售价：通用价格仍按公开模型名共享；官方视频仍绑定既有 ModelConfig 的 ChannelID 和 ProviderScopeID。重复模型、映射别名与官方配置的关系需明确展示。普通管理员只使用原有通用价格权限，官方成本和发布仍要求 active superadmin。

## 二、火山规则填充

仅从受版本控制、摘要核验通过的官方目录生成 2.0、2.5 候选规则。按语义列读取 CNY/百万 Token，输入时长为 0/大于 0 区分无/有参考视频，分辨率独立匹配；同格冲突即拒绝自动填充。Fast/Mini 不冒充标准版，1.x 不进入配置。

官方成本、示例金额、估算 Token 和最低量分开。自动填充保留当前 USD 售价、启用状态、风险系数及能力边界；缺少售价或未验证能力的格子只作为待配置项。最低量保持来源、原始精度和维度覆盖说明，不能把示例用量或未知 FPS 伪造为已核验规则。最低规则的登记与价格发布继续使用显式操作和审计；浏览/切换厂商不写收费配置。新预填接口不发起上游调用。

当前请求行为保持：没有有效价格组合拒绝创建；实际结算使用已确认官方计费 Token 及创建时价格快照。CNY 官方成本不直接写入 USD 售价。

## 三、文档信息架构

左侧仅三个可折叠顶层分类，支持深链接、选中项、键盘操作和窄屏导航。每篇按“用途 → 鉴权 → 参数 → 示例 → 返回 → 错误/限制”组织。公共接入说明放在首页正文或所属分类内部，不增加第四个顶层分类。

- 文本模型：接入与模型发现、Chat、Responses、Embeddings、流式和错误处理；只列实际可调用接口。
- 图片模型：模型与计费介绍、图片生成、图片编辑及返回/用量说明；模型名来自真实目录或明确占位，不虚构已上架模型。
- 视频模型：Seedance 2.0/2.5 介绍与能力查询、预估、创建、列表/查询、取消、删除、私有产物读取；真人/虚拟素材组、认证、素材上传/登记/查询/编辑/删除及异步操作状态；计费、冻结/结算、请求 JSON 留存与回读说明。

客户使用平台 Bearer Key，不提供火山 Key/AK/SK 给下游；本平台路由、模型名、Idempotency-Key、任务状态、产物鉴权和能力门控以真实实现为准。取消受理不等于已经退款，删除不等于取消，真人认证不替代商业使用授权。JSON 已过期或未采集明确显示，不能承诺永久留存。

公开 OpenAPI 与网页同时核对，纠正旧 doubao 模型名、旧状态、任意参数透传、失败全退款等不适用说明。参考来源：https://docs.ai-tokenhub.ai/zh/ai.TokenHub 、https://docs.ai-tokenhub.ai/zh/api-guides/Dreamina-Seedance-2.0 。不复制其平台承诺或外部私有接口。
