## 交付范围

- `/app/admin` 定价：厂商 → 已接入渠道 → 实际渠道模型；按已有计价事实展示 Token、图片、按次、音频或官方视频编辑器。无法确定的类型明确标记未知，保留全部字段。
- 官方视频只配置标准 `seedance-2.0`、`seedance-2.5`。1.x、Fast、Mini 不继承标准版规则；渠道原名/别名经当前绑定配置映射到公开模型。
- `/docs`：文本、图片、视频三个折叠分类，共 17 篇；提供搜索、深链接、手机目录、cURL/输入/响应示例。公开 OpenAPI 3.1 共 33 路径、42 操作。
- 定价详情、规则来源、最低量与历史版本均通过共享右侧抽屉显示。

## 实际验收结果

1. 本地 API 逐项比较全部 14 个成本值、维度、来源行、最低量覆盖数及 2.0 未知 FPS；检查渠道原名映射、1.x/Fast 拒绝和未登录访问拒绝，全部通过。
2. Chrome 实际选择火山、渠道模型 2.0 与 2.5：正确呈现 8/6 个官方组合，分别补入 7/5 个缺失成本草稿，既有单元格保持。未发布新增组合。
3. 最低量抽屉支持搜索和 20 项分页；筛选 2.0 的 480p 得到 72 项、4 页。抽屉在 1366×768 视口内覆盖右侧，关闭按钮在视口内。
4. 文档三个分类可折叠；视频任务深链接、请求 JSON 切换、`expected_version` 搜索通过。390×844 下目录可展开、选文档后关闭，页面无水平溢出。
5. 验收前后比较视频价格/配置/能力版本、完整通用价格字段、汇率版本与账户余额，全部不变。此轮没有发送官方生成请求，新增官方费用为零。

## 边界与依赖

保留原定价策略：未配置客户售价的组合不会自动用官方成本兜底或发布。实际支持范围仍由已核验能力与价格版本约束，表中存在参考值不等于开通能力。

本次同时补齐公开素材/组 GET 的 `version`，供 PATCH 的 `expected_version` 乐观锁使用；输入 Token 语义改为“平台未单列，按实际 completion_tokens 计费”，不将未知值解释为官方输入为零。过期或此前未保留的历史请求 JSON 无法由文档改造恢复。

三个功能分支分别对应后端 #25、定价 UI #26、文档 #27，均基于 #24；最终集成分支为 `codex/maas-provider-pricing-docs`。集成不等于合并 main 或生产部署。
