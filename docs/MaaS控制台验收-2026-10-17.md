# MaaS 控制台本地验收

本轮从 PR #19 的 `22a06a1` 继续开发，执行范围为《MaaS平台补齐执行计划-2026-10-17.md》的 S1。全站差距与后续工作包已登记，不将未开发的 Project、模型审批、发票、工单、客户 SigV4 等领域计入已交付。

## 用户确认的定价策略

只补官方参考价；保留现有客户 USD 售价；新增组合暂不发布。官方目录是代码内固化的只读来源快照，无数据库写入、能力开启或价格发布动作。

官方单价、估算 Token、舍入后的示例视频金额分别标明单位与精度。最低 Token 参考表是官方估算，不自动导入当前收费规则，也不从金额反推用量。最终用量仍以供应商返回和既有任务结算协议为准。

## 详情入口

以下页面复用同一个右侧 DetailDrawer：

| 页面 | 只读入口 |
|---|---|
| 模型目录 | 模型详情 |
| Key | 脱敏 Key 详情 |
| 账单、动账流水、充值 | 账单/流水/充值详情及关联记录 |
| 通用日志、Seedance 日志 | 请求详情与原有授权正文读取 |
| 通用与官方视频操练场 | 已接收的请求/响应详情 |
| 私域素材库 | 素材详情与媒体预览（含所属组 ID） |
| 管理后台 | 调用与审计详情 |
| 视频定价 | 官方目录信息、来源证据、历史价格版本 |

共享抽屉有固定标题/关闭区、独立滚动正文、Esc 关闭、Tab 焦点约束、关闭后焦点恢复和窄屏全宽行为。创建、编辑、认证、支付和删除确认仍保留各自业务操作流程。

打开详情不会重新生成视频。切换组织、Key 或身份时，旧异步结果不能重新打开或填入私有详情。旧操练场的任务恢复按组织与 Key 指纹隔离，切回原上下文仅 GET 查询，不重新提交或取消供应商任务。

## 验证边界

- Go：core/relay vet、迁移 lint、全量测试和编译。
- Web：i18n、TypeScript、Vite 构建、模型目录 2 项、操练场上下文 7 项、视频定价上下文 6 项回归。
- GitHub：Go、Web、真 MySQL 迁移重放/事务集成/并发以及红线检查。
- 本地：官方目录完整度与行数、访问权限、现有价格/配置快照和余额前后比较、浏览器抽屉与筛选验收。
- 本轮没有新增付费视频生成；网络回归使用模拟响应。本地验收仅查询现有任务、来源和账务记录。

来源：[火山方舟视频生成模型价格快查表](https://bytedance.larkoffice.com/wiki/FXaYwxzJ5i5Zdik32ipcWzt7nxd)。单位和最低量估算语义同时核对[官方模型价格文档](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)。

| 官方表 | 独立视图 | 原始行数 |
|---|---:|---:|
| Seedance 2.5 价格 | 1 | 48 |
| Seedance 2.5 最低 Token | 1 | 339 |
| Seedance 2.0 / Fast / Mini 价格 | 3 | 104 |
| Seedance 2.0 最低 Token | 4 | 192 |
| Seedance 1.5 价格 | 1 | 12 |
| Seedance 1.0 Pro / Pro Fast 价格 | 2 | 24 |
| 合计 | 12 | 719 |

每个视图保留原始 TSV、字段顺序、来源链接、采集时间和 SHA-256。2.0 最低量的 4K 视图有 7 列，其他分辨率有 6 列，按各视图原列展示；不补造统一列。1.5 的有声、无声、Draft 各价格列保留原名，未由数值推断在线/离线等未显示含义。空白不是零价。

运行时只读接口为 `GET /api/admin/video/official-price-catalog`，限有效实名超管，响应禁止缓存；共享管理员令牌不能代替个人审计身份。

## 验收结果

2026-10-17 将本地 `127.0.0.1:5174` / `127.0.0.1:8082` 更新为集成分支；保留原 MySQL 数据。代码集成点 `3c6dfd1` 的完整本地 CI 通过，文档提交前再次执行 core/relay vet 通过。

只读接口复核时间为 `2026-10-17T15:02:43Z`：目录完整标志为 true，6 表、12 视图、719 行；匿名访问被拒绝。seedance-2.0 / seedance-2.5 现有价格及配置 JSON 与更新前完全一致，余额与冻结额不变，付费生成请求数为 0。

浏览器实际检查结果：

- 2.5 价格按 1080p、含参考视频筛选得到 9 行；2.0 最低量按 480p / 4K 切换后保留各自 6 / 7 个原始字段。
- 桌面 1920 × 855 下普通详情抽屉靠右、宽 640，正文独立滚动；Esc、焦点约束及关闭后焦点恢复正常。
- 手机 390 × 844 下抽屉全宽、关闭按钮可见、页面没有横向溢出。验收后恢复默认窗口尺寸。
- 请求 ID 可进入 Seedance 详情；任务结果 JSON、供应商用量、计价维度/版本及冻结、扣费、解冻记录均可查看。滚动正文时标题与关闭按钮固定。
- 历史请求正文已超过留存期的显示“已过期”；历史未记录的上游请求显示“未保存”。不会把任务结果伪装为实际请求 JSON，也不会补造历史正文。
- 切换组织后，旧组织的任务列表及详情不会残留；切回原组织后可继续查询其记录。
- 动账流水的关联任务入口在右侧展示资金操作详情。

本地截图保存在工作区 `.cache/maas-acceptance/`，仅作本地验收证据，不随 PR 上传用户任务数据。没有开展新的真实出片测试；前述验收不能替代供应商新任务端到端验证。
