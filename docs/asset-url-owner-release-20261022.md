# 素材网址直传与个人资源隔离发布

## 变更与边界

未登记的公网 HTTPS 网址可直接注册火山，平台只保存加密执行内容与资源元数据，不下载、扫描或保存媒体。官方图片入库后可引用；视频/音频缺少可信时长时仅允许注册和查询，不按 0 时长计费。素材预览从固定管理接口取临时地址，浏览器直连，无平台令牌转发。

普通用户按组织和创建者读取、同步、预览、修改、删除、引用资源。同一具名用户的多个 Key 共用个人资源，无具名用户的 Key 独立。超级管理员在明确组织上下文内管理资源。共享项目仅共享配置，不共享资源、视频执行权限或历史留存同意。

素材请求日志按原请求用户隔离。旧素材响应可能包含其他创建者数据，普通用户仅可读取本人请求正文，不开放素材响应原文；管理员仍可审计取证。普通用户同步保留安全回执，不保存可能混合创建者的官方整页响应原文。

## 迁移与验收

1. 停写窗口前保存数据库、配置、旧镜像及正式源版本。只向 main 合并通过全部门禁的提交。
2. `0124_video_asset_ownership.sql` 新增所有者关系。历史组/素材只按已认证请求及精确操作/作用域归属，真人/上传使用已有归属证据；无证据为 0/0，管理员可见。没有重写资源、旧请求、任务或账务。
3. `0125_video_asset_shared_default.sql` 新增共享配置，初始禁用。升级不自动选择火山凭据，也不改变组织现有路由或策略。
4. 独立 MySQL 验证旧 123 版升级、具名/未具名/错组织/错作用域等历史样例、重复迁移及 schema-doctor。线上候选核验旧业务与账务行未被迁移更改，关系表与证据推导逐行一致。
5. 本地更新源码、依赖与实际运行镜像，保留 ArkControl 本地覆盖文件。验证前端运行版本、URL 注册入口、共享配置和仅本人资源范围，避免只改源码却仍运行旧版本。
6. 线上候选通过健康、资金、迁移及静态资源校验后开放流量。使用具名管理员会话发布已有 `LAIAI-Gateway` 管理版本为共享默认，不重复存放 AK/SK；已有组织专属路由及显式禁用策略仍优先。
7. 官方管理冒烟只使用新建的临时资源：创建组、注册 HTTPS 图片、查询官方状态、预览 URL、同用户/其他用户访问、删除临时素材、删除空组。原有 `gg`、`kk` 与用户素材不作为删除样本。不调用付费视频生成。

## 回退

迁移为新增表，但旧版本没有创建者隔离。**不能仅因数据库向前兼容就把旧二进制重新公开给普通用户**。回退时保留维护模式/关闭素材公开入口，恢复经验证的兼容修复版本后再放行；共享默认撤销不会删除任何素材或历史记录。不得回删 owners 数据、按同名认领资源，或把官方未知提交重新发送来恢复状态。

官方依据：[虚拟素材库指南](https://docs.volcengine.com/docs/ark/private-virtual-avatar-library-guide-preview?lang=zh)、[GetAsset](https://docs.volcengine.com/docs/ark/get-asset-api?lang=zh)。真实上线与官方冒烟结果另存发布记录，不以模拟回归代替。
