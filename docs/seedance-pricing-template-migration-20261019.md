# Seedance 定价模板迁移与复用（2026-10-19）

模板版本：`seedance-20261019-v1`。来源为本地后台当前已发布的四个 Seedance 模型价格，迁移安装后可在其他环境和接入配置中复用，无需复制本地业务数据库。

各模型最低用量分别为 288、486、144、144 个条件，使用各自独立版本。模板依赖明确的官方证据摘要；证据版本不匹配时应重新核验并发布新模板。Seedance 1.x、未开放的编辑/续写/Draft 条件不包含在模板内。

## 已接入模型复用

管理后台 → 定价 → 对应 Seedance 模型 → 应用定价模板，在右侧抽屉选择版本并预览差异。

1. 默认“仅补缺失组合”：已有价格、已停用组合和隐藏模式完整保留。
2. 显式选择替换时，仅替换模板覆盖的价格参数，已有启用/停用状态保留。
3. 新补齐的组合默认停用；应用先写入当前编辑草稿，管理员确认启用范围后，再经过现有价格预览、校验、发布流程。
4. 发布记录保存模板版本和摘要；切换渠道、配置版本变更或模板摘要不匹配时须重新预览。

接口均要求有效超管会话：

```text
GET  /api/admin/video/pricing-templates?model=seedance-2.0-fast
POST /api/admin/video/models/seedance-2.0-fast/pricing/template-preview
POST /api/admin/video/models/seedance-2.0-fast/pricing/prepare
POST /api/admin/video/models/seedance-2.0-fast/pricing/validate
POST /api/admin/video/models/seedance-2.0-fast/pricing/publications
```

预览请求的 `channel_id` 和 `expected_config_version` 来自当前目标模型配置，`template_version` 为模板版本，`mode` 为 `fill_missing` 或 `replace`。预览返回完整价格矩阵与 `template_ref`；prepare 请求沿用该引用，之后按服务端返回的完整请求校验和发布，发布需 `Idempotency-Key`。

## 新环境首次接入

正式 `POST /api/admin/video/configurations` 支持可选 `pricing_template`，内容为模板列表返回的 `{version, model, sha256}` 引用；与手写 `prices` 互斥。服务端据此生成价格并在同一配置事务中导入匹配的最低量证据。

首次发布必须传入 `Idempotency-Key`，显式提供模型、配置版本、价格版本、目标渠道及模型启用状态。配置对象沿用现有接口字段名：`CapabilityJSON` 和 `BoundsJSON` 可以一起省略，由模板对应的已核验官方资料填入精确上游模型、像素边界和参考视频时长限制。

目标环境仍需提供真实渠道绑定、明确的账户/区域/项目、FX 快照和日/月供应商预算。已有账户作用域的 FX 必须保持一致。免费释放终态 `NoChargeStatuses` 继续按该渠道的核验结果显式配置，模板不推断取消或失败任务是否免费。模板不会猜测这些字段，也不扩大权限或绕过预算。发布失败时完整回滚，不留下半套价格或最低规则；相同幂等键和相同请求重放不重复写入。

现有架构仍是每个公共模型一个当前执行配置；模板可跨环境复用，也可用于明确重新绑定后的价格配置，不改变这一渠道路由约束。

## 升级与回退

正常版本迁移仅安装模板库，不覆盖线上已有售价、不开放新模型、不重置历史消耗。迁移重复运行由版本记录保证幂等；种子行发生人工冲突时失败，禁止用覆盖写法修复。

升级前保留生产备份及原加密密钥、持久卷，核对现有迁移记录。升级后确认模板数为 4、有效价格共 22 格，再预览目标渠道。需要恢复原售价时通过正式价格发布操作生成新版本，不能编辑已受理任务的冻结快照或直接修改账本。

本轮模板验证不需要向火山新增付费生成请求。此前四组 Fast/Mini 的真实调用与结算结果见 [接入验收记录](seedance-fast-mini-acceptance-20261019.md)。
