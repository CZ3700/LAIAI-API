# 模型定价重设计验收记录

日期：2026-10-19。基线：PR #29 / `20b269dc63f77c925a4fed61c852b9bc01840859`。本轮改造模型目录和定价操作路径，未修改结算引擎，也未发布新的运行价格。

## 交付

- `/models`、`/app/models` 共用模型目录：搜索、厂商/类型/计价单位/端点筛选、卡片与列表、URL 保留筛选；详情右侧抽屉提供实际售价和接入示例。
- 后台 `/app/admin?tab=prices` 从真实渠道模型选择厂商、类型和状态。通用价格仍按对外模型名共享，保留全部现有价格字段；厂商沿用渠道注册表。
- Seedance 标准 2.0/2.5 默认显示分辨率 × 有无参考视频售价表。规则、官方参考和发布记录单独页签；未核验组合折叠，其他任务模式保留；1.x 排除，Fast/Mini 不借用标准版价格。
- 预览使用服务端 prepare → validate，完整保留未修改组合和隐藏字段；发布校验完整矩阵、配置版本、可信来源集合，任何编辑都会使旧预览失效。源材料 hash、来源集合 hash 和提交体 hash 分开记录。
- 公开视频价格按已发布、可调用组合投影，不再以通用输入/输出 0 代替；不输出成本、内部渠道、账户作用域和证据。通用全零未配置价不视为免费，已有单侧零价保留。
- 原视频定价链接按实际授权目录及绑定渠道定位，未知或歧义模型显示明确提示，不猜测渠道。所有新增详情/编辑/预览使用右侧抽屉。

## 已知边界

- 官方参考价不会自动成为客户 USD 售价，也不会自动启用未验证组合；未定价/未核验时继续阻断调用。
- 本轮未扩大当前已核验的分辨率、参考视频或任务模式范围。其他组合需要补齐能力和最低 Token 证据后独立发布。
- 新目录文案以简中、繁中、英文为完整版本，其他语言部分新增技术说明回退英文；后台新增文案以中文/英文为主。所有语言消息包均可编译。
- 公开目录只展示平台公共渠道，私人 BYOK 模型发现不在本轮扩展。
- 请求 JSON 留存、素材库和账单流水继续沿用已有实现，本轮不重复改造这些模块。
