# G2-A1 组成员关系与模型候选解析实施契约

2026-10-26，主控已审查并决定实施。基于已验收main b21308ba4dc08d4f5c2757fe2c32746167d352ac；本契约与整体架构设计先于代码落盘。实现与验收尚未完成，不代表分组Key可用。

## 1. 本批范围与已确定边界

主控已批准 A1 采用**最小候选解析层**。本批名称只用 Candidates / GroupMembership，不使用 Allowed、EffectiveModels、授权票据或发送许可等名称。

本批交付：纯集合规则、显式内部 DTO、读取当前 schema 的同事务有限事实接口、组成员关系/公有模型候选解析、纯规则与真实 MySQL 验收。无缓存、不挂生产路由、不接入 relay/video/task 调用、不改变 `IssueKey` / `VerifyKey` / `AllowsModel` 的分组模式关闭行为；无策略版本 DDL、无任务授权记录 DDL。

以下决定已固定，但都不在 A1 实施：

- 完整 G2 的官方视频仍固定 `ModelConfig.ChannelID`，不扩展视频 BYOK。
- 后续独立授权受理记录与账务快照、既有 execution capsule/HMAC 隔离。
- 同 body 的历史幂等 POST，在当前 Key/scope/Org 有效时只读返回原回执，不新增冻结或派发；后续独立修改和验收。
- 最终授权许可是后续发送路径的线性化边界；已许可的在途请求不承诺撤权提交后零网络包。
- 价格发布、精细接口能力、Org 功能与 Key scope 的实际组合以及最终许可另批接入。A1 不添加一个尚未实现的 PublicationReader，也不伪造其返回成功。

## 2. 本批能证明什么

A1 返回的是：在调用方当前事务观察到的 Key 模式、Org/成员状态、组及授权关系下，哪些**启用且合法归属的已绑定渠道**在 `Channel.Models` 中发布了某个公有模型名称，且该名称符合 Key subset。

它不是实际可调用模型清单。即使结果非空，仍未证明：价目已发布、请求参数受能力支持、Key scope 允许接口、Org 已开通该动作、余额/预算足够、上游额度/健康可用、当前 credentials 可用或最终发送权限仍有效。Org 功能与 Key scope 以独立事实输出，不能被消费者误认为已组合核验。

`genericDescriptor.Endpoints` 由展示元数据选择文档引导；`SupportsCatalogMode` 也不保证具体模型能力。这两者不进入 A1 集合计算。不得把它们改名后当作授权依据。

## 3. 领域归属与拟冻结签名

以下为本批冻结的新增 API；当前代码尚未实现。实现偏离需主控审查。

### 3.1 routinggroup 拥有的内部解析 API

```go
type CandidateSubjectRef struct {
    OrgID uint64
    KeyID uint64
}

type CandidateResolver struct {
    Subjects CandidateSubjectReader
    Channels PublishedChannelReader
}

func (r *CandidateResolver) ResolveModelCandidatesTx(
    ctx context.Context, tx *gorm.DB, subject CandidateSubjectRef,
    model string, at time.Time,
) (ModelCandidates, error)

func (r *CandidateResolver) ListModelCandidatesTx(
    ctx context.Context, tx *gorm.DB, subject CandidateSubjectRef,
    page ModelCandidatePage, at time.Time,
) (ModelCandidatePageResult, error)

type CandidateSubjectReader interface {
    ReadCandidateSubject(context.Context, *gorm.DB, CandidateSubjectRef, time.Time) (CandidateSubjectFacts, error)
}

type PublishedChannelReader interface {
    ReadPublishedChannels(context.Context, *gorm.DB, []uint64) ([]PublishedChannelFacts, error)
}
```

解析器没有 `DB` 字段、不自行开事务；只能使用参数 `tx`。`subject` 是经过宿主身份确认后选择的引用，不是鉴权令牌。本批仅测试/内部调用，绝不能暴露“任意 KeyID 查询授权”的公开接口。不得接受输入 mode、group_id、subset 或版本来替代数据库事实。

### 3.2 DTO（均为内部类型，不直接序列化 HTTP）

```go
type CandidateSubjectFacts struct {
    Found bool
    OrgID, KeyID uint64
    KeyActive, KeyExpired, PrincipalActive bool
    Mode string
    RoutingGroupID *uint64
    KeyPolicyVersion uint64
    ModelLimits string
    KeyScopes string
    FeatureImages, FeatureVideo bool
}

type PublishedChannelFacts struct {
    ID, OwnerOrgID uint64
    Enabled bool
    Models []string
}

type CandidateObservation struct {
    OrgID, KeyID, GroupID uint64
    KeyPolicyVersion, GroupPolicyVersion, GrantVersion uint64
    ModelAccessMode string
    CheckedAt time.Time
    Assurance string // 固定 group_membership_only
}

type CandidateContextFacts struct {
    KeyScopes string
    FeatureImages, FeatureVideo bool
}

type ModelCandidate struct {
    Model string
    ChannelIDs []uint64 // 升序、去重，只含本组合法启用渠道
}

type ModelCandidates struct {
    Observation CandidateObservation
    ContextFacts CandidateContextFacts
    Candidate ModelCandidate // 没有该候选时 ChannelIDs 为非 nil 空数组
}

type ModelCandidatePage struct {
    AfterModel string // 公有模型名的排他游标；空表示首批
    Limit int         // 0 默认20；有效范围1..100
}

type ModelCandidatePageResult struct {
    Observation CandidateObservation
    ContextFacts CandidateContextFacts
    Items []ModelCandidate
    NextAfterModel string
    HasMore bool
}
```

`Assurance` 无法被调用方参数覆盖。`CheckedAt` 只是本次传入可信时钟的核验时刻，不是数据库提交时间、版本水位或后续有效期限。三个观察版本不是完整策略版本向量，不能作为可重用许可、完整 ETag 或缓存键。

单模型未匹配可正常返回空 ChannelIDs；目录合法零项返回 `items:[]`。这两种情况必须与读取错误、主体拒绝、超限分开。输出不带 group/channel 名称、上游名、BaseURL、ModelMapping、DetectedModels、IP 白名单、Key hash/指纹、credential 或任意原始错误。

### 3.3 identity 拥有的有限事实读取

拟新增在独立文件 `identity/routing_candidate_access.go`：

```go
func ReadRoutingCandidateSubjectTx(
    ctx context.Context, tx *gorm.DB, orgID, keyID uint64, at time.Time,
) (RoutingCandidateSubject, error)
```

`RoutingCandidateSubject` 是 identity 自有 DTO，字段与上面的 CandidateSubjectFacts 一一对应。宿主桥接显式转换，identity 不返回 routinggroup DTO，避免把读取层耦合到解析结果。

- 用 `id=? AND org_id=?` 读取 Key 白名单列。缺行是 Found=false；数据库错误绝不能伪装缺行。
- 不调用 `VerifyKey`，因为它按 G1 正确拒绝所有分组 Key；新 reader 只是读取事实，不验证明文、不签发、不打开任何数据面。未知模式原样作为事实交给解析器拒绝，不能规范化成 legacy。
- KeyActive 严格取当前已知 active 状态；过期与现有 VerifyKey 的时钟语义保持一致，不顺便修改到期边界。at 必须非零且是宿主可信时间。
- PrincipalActive 等价于当前 `VerifyActiveMembership` / `VerifyOrgActive` 所依赖的存在与 active 状态：成员 Key 必须 Org、User active 且成员关系仍存在；无成员 Key 查 Org active。只读同一 identity 域表，缺实体是明确 inactive，SQL 故障独立返回。
- entitlement 缺行使用现有明确默认；真实查询失败返回错误。FeatureImages/FeatureVideo 仅作为正交事实，A1 不据此猜模型类别。
- 最多三个业务 SELECT：Key、主体现状（identity 域内一次关联/存在性查询）、entitlement。Key 缺行可以提前返回。禁止加载 User 密码/TOTP、完整 Key 或 Org 全行。
- ModelLimits 和 KeyScopes 各自最多 32 KiB；超限返回固定 limit 错误，不截断成更宽权限。实际读取采用长度检查/受限投影，不能先加载任意大的 TEXT 再宣称有内存上界。

### 3.4 relay 拥有的已发布模型事实读取

拟新增在 `relay/routing_published_access.go`：

```go
func ReadRoutingPublishedChannelsTx(
    ctx context.Context, tx *gorm.DB, ids []uint64,
) ([]RoutingPublishedChannel, error)
```

`RoutingPublishedChannel{ID,OwnerOrgID uint64; Enabled bool; Models []string}`，宿主显式转换。只读取 `id,owner_org_id,status,models`，不读取映射、provider credential、配置 URL、模型检测结果或缓存。

ids 必须正数、严格升序、去重且最多100；空集合返回非 nil 空数组，但仍验证真实事务和 context。缺行省略，解析器知道它是悬空绑定，不能从其他渠道补齐。一个批次至多一次 SELECT，无按渠道 N+1。

Models 保留现有 CSV 的逗号拆分、每项 TrimSpace、去空、按公有名精确比较语义；去重后以 Go 字符串字节序排序，不大小写折叠、不应用 ModelMapping。每个 `models` 原始值最多64 KiB，全部渠道原始值累计最多1 MiB；每项最多128 Unicode字符且512字节，要求有效UTF-8，不含NUL/控制字符；违反返回固定 limit/invalid-facts 错误，不能忽略异常项后给出“完整”结果。长度受限投影先于大字段加载，超限标记不可当空字段。

上述为读取层防御边界，当前真实MySQL schema的scopes为VARCHAR(255)、models为TEXT（最多65535字节），不为测试放宽列定义。实际数据库验证既有列上限及数据库拒绝；更大防御分支由快速测试覆盖，不能声称MySQL成功持久化了不可能的超长字段。累计1MiB用多条合法TEXT组合验证。单批受限投影临时传输仍最多100×64KiB，1MiB是完整结果的语义门槛，不是读取期间内存或网络绝对上界。

## 4. routinggroup 解析规则与读取顺序

1. 校验非 nil 依赖、正 Org/Key、合法 model/page/at、真实 tx 和未取消 context；无效请求零 SQL。
2. 读取 SubjectFacts，必须精确回显 Org/Key，Found、KeyActive、PrincipalActive 为真、KeyExpired 为假，KeyPolicyVersion>0。错误身份或主体不可用返回固定拒绝；不能继续查组暴露其信息。
3. A1 只解析 `inherit_group` / `subset`。legacy 返回专门的 `ErrCandidatesLegacyMode`，不返回“全渠道”；调用方不能把它当作默认组。现有 legacy 生产实现不变，并用兼容测试锁定。未知 mode 或非法组合返回 invalid-facts；inherit_group 有非空 ModelLimits 或 subset 为空也拒绝。
4. 组必须存在、enabled、PolicyVersion>0，owner 为0或subject.OrgID；授权必须存在、enabled、GrantVersion>0且Org/group完全匹配。组停用、撤权、不可见组统一固定拒绝，不返回组内容。未知状态/零版本为损坏事实，固定 invalid-facts，不当 legacy。
5. 读取该组 bindings，按 channel_id 升序，固定 LIMIT 101；超过100直接 `ErrCandidatesLimit`，不截前100当完整集合。此上限是 A1 查询边界，不写入组管理政策、不修改 G1 可配置数量。
6. 对最多100个已绑定 ChannelID 一次读取事实；严格校验返回 ID 在输入内、唯一。未知额外 ID 或重复事实是依赖错误。缺失、停用或非法归属的渠道不成为候选：平台组只可含 owner=0，私有组只可含 owner=组Org。不能借绑定读取别人凭据或跨 Org 模型。
7. 公有模型候选取这些渠道 Models 并集；subset 再精确相交。至少一条合法启用渠道服务该公有名才产生候选。某个悬空/停用绑定不扩大集合，其余正常渠道仍可返回。
8. 返回前再次检查 context。任何阶段失败均返回零值结果与错误，不返回已读部分页、错误合计或陈旧结果。

安全集合规则可由不导出的纯函数实现，输入使用上述已验证有限 DTO。公开 API 仍负责读取与结构验证，不能以一个客户端提供的 DTO 作为权威事实。

## 5. 单模型与目录的有界性

当前 schema 用 `Channel.Models` CSV，无法为“公有模型包含关系”提供正常关系索引。本批不假装拥有数据库 model seek 索引，也不新增规范化模型表。

- 单模型 API 只组装目标名称的 ChannelIDs，不构造完整目录或逐个模型读价目。仍需读取最多100个已绑定渠道的有限 CSV，这是当前 schema 的真实成本。
- 目录 API 在同样有限事实中计算完整候选集合，最多1000个不同公有名；超限整体报 `ErrCandidatesLimit`，不能返回不完整总集合的成功分页。每模型关联渠道最多100。
- 排序与 AfterModel 都采用 Go 字符串字节序、精确公有名；不借 MySQL 大小写不敏感/PAD SPACE 比较做成员判定。返回 limit+1 观察决定 HasMore，NextAfterModel 为本页末项；无下一页为空。
- 跨请求分页是 live 查询，可能因组配置变化增减；不保证固定快照，不提供合计/跨页版本锁定。每个响应内部来自同一事务。不同请求看到版本变化时，上层未来应重新加载，A1 不新增缓存/session。
- 业务 SELECT 上界：identity最多3 + group1 + grant1 + bindings1 + channels1，总计最多7。没有 COUNT 全表，无 OFFSET，无关联 Key 全表扫描；模型1000项 CPU处理受总字节上限保护。
- A1 共同调用期限1秒，每次 SELECT 子期限不超过200ms且不能超过调用方剩余期限。MySQL使用局部 `MAX_EXECUTION_TIME` hint和context，SQLite仅用于快速行为测试；期限不是强制外部 HTTP预算，因为本批完全不发HTTP。

## 6. 同事务、错误与安全日志

Tx API 只接受具有真实 TxCommitter 的事务，拒绝普通 DB句柄、DryRun、nil context/Statement/配置、已失败tx和不支持的dialect。支持 MySQL 和快速测试SQLite；不尝试通过 Mock GORM句柄证明真实锁/隔离。

caller负责在主库开启RR事务，首个一致读之前决定本次时间。A1生产无caller；测试宿主采用 `sql.LevelRepeatableRead + ReadOnly:true`。reader不 Begin/Commit/Rollback、不替换连接池、不查询只读副本、不升级为 UPDATE 锁。底层Tx API自身只读，不声称能检测/强制调用者此前创建的事务隔离级别。另用可写tx验收“可看到同事务未提交事实且不另开连接”，结束由测试回滚。

每条查询 `Session(NewDB:true, Context:子context, Logger:Discard)` 一次设置，清理调用方残留 Where/Select/Order/Limit但保留相同ConnPool。不能 NewDB 后再额外 WithContext 意外继承旧链；已存在相似跨域reader回归可借鉴但不复制有缺陷模式。局部静默 SQL 日志，错误不反射 SQL、model输入、Key字段或驱动参数。

建议新增专用固定错误，不复用会混淆管理命令的文案：

| sentinel | 语义 |
| --- | --- |
| ErrCandidatesInvalid | 非法调用参数/非真实事务 |
| ErrCandidatesDenied | 当前主体或组授权明确不满足；不可见组不区分具体存在性 |
| ErrCandidatesLegacyMode | 本解析器不处理legacy；不是授权成功或自动回退指令 |
| ErrCandidatesInvalidFacts | 持久模式/版本/关系描述损坏，或桥接返回非法事实 |
| ErrCandidatesLimit | 已知数据超过本批完整解析上界；不是空集合 |
| ErrCandidatesUnavailable | DB/桥接/事务等依赖失败 |

错误文本全部固定。取消/超时保留 `errors.Is(context.Canceled/DeadlineExceeded)` 并可同时分类 unavailable；不将驱动原错文本写到日志/DTO。各reader拥有自己的安全sentinel，server桥接显式映射到routinggroup语义。事务结果不完整、必需reader/DB/主体关系缺失均失败关闭；这不包括第4节明确允许从候选中排除的悬空Channel绑定，正常缺行与数据库读取失败必须区分。

## 7. 本批不证明的现有 schema 缺口

- group/grant/Key三个版本不覆盖 Channel.Models/status、Org entitlement、模型能力与价格。A1只给当前事务观察值，不能作为跨请求CAS票据或授权缓存键。
- 当前Key可purge、Task/State无组授权受理记录；A1不向任务“补快照”，不凭当前default重建历史。
- ModelConfig固定单Channel仅是后续方案约束；A1不读ModelConfig，因而不能声称已经验证官方视频能发起。
- Org功能/Key scope只是原始安全事实；“组里有候选模型”不代表视频异步政策已启用或该Key具有video:write。
- 此只读RR观察不能用于最终发送前撤权复核；后续必须定义current-read/许可顺序与已有Task/State/账务锁序，不可直接把本API塞进最终guard声称完成。
- A1未覆盖用户IP、RPM、额度、预算、请求参数、credential可用性、熔断、scope并发、全入口接线。它只为完整G2提供一个统一的候选层。

## 9. 测试与合并门槛

### 9.1 纯规则与快速测试

- 固定手工oracle：平台/私有组、同/异Org、状态/悬空绑定、多个渠道同名、subset交集、空subset拒绝、inherit携带limits拒绝、未知mode/version拒绝。
- Models大小写精确、TrimSpace兼容、上下游别名分离、DetectedModels不参与；重复和多字节名称排序；model/page参数非法零SQL。
- 功能开关关闭或KeyScopes为空仍只作为独立事实，不误称完整Allow；ModelCandidates始终Assurance固定。
- 合法0项与SQL错/限额/取消严格分开，错误后不保留已读结果；legacy sentinel不扩大生产权限。
- 100/101绑定、1000/1001不同model、每字段/总字节边界、Page20/50/100及游标；任何超限不成功返回部分数据。
- Warning级logger正控可捕获普通SQL，调用新reader/resolver时失败/慢查询不含SQL或机密参数。

### 9.2 真实MySQL（本机skip不计验收）

1. 独立随机schema，使用真实tracked迁移含0129；用现有合法group/grant管理域构造关系。grouped Key仅测试DB按既有CHECK合法写入；不新增生产签发旁路。每用例仍断言VerifyKey/AllowsModel/IssueKey按原G1拒绝。
2. 主库RR只读事务中运行真实resolver+identity/relay桥接；记录实际ConnPool相同、无额外Begin。另用可写tx建立未提交Models/grant变更，证明读取同连接后rollback无持久变化。
